# vgavard-electricite.com

Version statique du site de Vincent Gavard, Électricité Générale (73420 Méry), reprise depuis son
WordPress d'origine.

Site de 4 pages, sans dépendance serveur : HTML, CSS et un peu de JavaScript, à publier tel quel sur
GitHub Pages. La racine du dépôt est la racine du site.

| Page | URL |
|---|---|
| Accueil | `/` |
| Prestations | `/electricien-savoie-aix-les-bains-chambery-annecy/` |
| Réalisations | `/entreprise-electricite-devis-rapide-annecy-chambery-aix-les-bains/` |
| Contact | `/contact-devis-rapide-electricien-savoie-chambery-aix-les-bains/` |

Les URL sont celles de l'origine, pour ne rien casser au référencement.

- `assets/` — ce que le site sert : images, police d'icônes, CSS, JS.
- `reference/` — la matière première de la reprise, conservée pour comparaison : le HTML des pages
  d'origine, le contenu extrait de la base WordPress, les CSS et JS d'origine (à lire, pas à
  réutiliser), et la copie complète des médias d'origine.
- `VERIFICATION.md` — ce qui a été contrôlé, comment, et ce qui reste à regarder.

Origine conservée hors ligne. Aucune modification n'a été faite sur le site WordPress d'origine.
